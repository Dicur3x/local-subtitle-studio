# Local Subtitle Studio

[English version](README.md)

Local Subtitle Studio — настольное приложение для создания субтитров без загрузки видео в интернет. Первая поддерживаемая платформа — Windows.

> Статус: ранняя MVP-версия. Уже можно установить локальные компоненты, выбрать аудиодорожку и создать экспериментальный SRT на языке оригинала. Перед публичным выпуском нужны дополнительные испытания на фильмах, сериалах, разных кодеках и типах озвучки.

## Что уже работает

- Выбор видео через перетаскивание или диалог открытия файла.
- Асинхронная проверка медиафайла без зависания интерфейса.
- Показ языка, названия, кодека, числа каналов, битрейта и частоты каждой аудиодорожки.
- Установка рекомендуемого набора в один клик и отдельное обновление FFmpeg/FFprobe и whisper.cpp без замены выбранной модели.
- Полосы загрузки, объём переданных данных и точный процент, когда сервер сообщает размер.
- Текст списка изменений прямо в приложении и отдельная необязательная кнопка официального источника.
- Три профиля Whisper: быстрый, сбалансированный и максимального качества. Silero VAD устанавливается вместе с моделью.
- HTTPS-загрузки, безопасная распаковка ZIP, ограничения размера и проверка SHA-256.
- Автоматическое применение путей к управляемым компонентам и возможность указать собственные пути.
- Видимый статус готовности FFmpeg, whisper.cpp, модели распознавания и VAD до запуска обработки.
- Извлечение выбранной дорожки во временный PCM WAV 16 кГц, моно, 16 бит.
- Локальное распознавание через whisper.cpp с автоопределением или поиском по одному из 100 языков прямо в выпадающем списке.
- Длинное аудио распознаётся перекрывающимися фрагментами по восемь минут с чистым контекстом Whisper, после чего возвращается на общую временную шкалу.
- Пять этапов обработки с общей шкалой и настоящим процентом whisper.cpp во время распознавания.
- Разделение длинных реплик по времени слов, перенос в сбалансированные строки и проверка пересечений, повторов, длины строк и скорости чтения.
- Консервативное объединение только соседних одинаковых реплик, осторожное восстановление однозначных форм с `ё` и предупреждения о низкой уверенности.
- Отмеченные проверкой реплики можно открыть и исправить прямо в приложении; их номера и временные метки не меняются.
- Сохранение UTF-8 SRT рядом с видео, в папке `Subs` или в выбранной папке. Существующие файлы не перезаписываются.
- Английский интерфейс по умолчанию и русский перевод по выбору пользователя.
- Минимальный мастер первого запуска.
- Подготовлены внутренние задачи сборки автономного Windows-приложения и portable‑ZIP; пользовательский выпуск пока намеренно не публикуется до расширенного тестирования.
- Отмена проверки файла, подготовки аудио и распознавания.
- Автоматическое удаление временного аудио после операции.

Медиафайлы никуда не отправляются. Текущая версия не использует облачные сервисы.

## Как запустить обычному пользователю

Когда проверенная тестовая сборка будет приложена к закрытому выпуску:

1. Распакуйте обычную сборку или portable‑ZIP.
2. Запустите `Local Subtitle Studio.exe`.
3. В мастере первого запуска выберите язык интерфейса и место сохранения субтитров.
4. Откройте **Компоненты** и установите рекомендуемые программы и модель.
5. Выберите видео, аудиодорожку и язык речи.
6. Нажмите **Создать SRT**.

Сейчас готового пользовательского выпуска ещё нет: проект запускается из IntelliJ IDEA или через Gradle. Схема упаковки уже предусмотрена, но это не означает, что текущий образец готов к распространению.

Устанавливать Java, Gradle, IntelliJ IDEA, FFmpeg или whisper.cpp вручную не требуется. Приложение содержит собственную Java-среду, а остальные компоненты устанавливает по запросу пользователя.

## Где хранятся настройки и компоненты

Обычный вариант использует `%LOCALAPPDATA%\LocalSubtitleStudio`. Это рекомендуемый режим: он не требует прав администратора, не изменяет системный `PATH` и не создаёт конфликтов с другими версиями FFmpeg.

Portable‑ZIP содержит файл `portable.mode`. В этом режиме настройки, FFmpeg, whisper.cpp и модели хранятся в папке `data` рядом с программой. Такой каталог следует распаковывать туда, где пользователь может записывать файлы, а не в защищённую `Program Files`.

Для опытного пользователя путь к данным можно задать свойством `lss.data.path` или переменной `LSS_DATA_PATH`. Собственные пути к программам доступны в расширенных настройках.

## Место сохранения SRT

В расширенных настройках доступны варианты:

- **Рядом с видео** — лучший вариант для автоматического обнаружения большинством проигрывателей.
- **В папке Subs рядом с видео** — удобно для сезона сериала или каталога с большим количеством файлов.
- **В выбранной папке** — удобно для экспорта, монтажа и последующей ручной обработки.

Имя имеет вид `<название видео>.<язык>.srt`. Если такой файл существует, создаётся номерной вариант, например `.2.srt`.

## Почему создаётся WAV

WAV не улучшает и не «апскейлит» AC3, AAC или другой сжатый звук. FFmpeg декодирует выбранную дорожку в точный несжатый формат PCM, который ожидает цепочка распознавания. Исходное видео открывается только для чтения и не изменяется.

Увеличенный WAV — временный рабочий файл. Он удаляется при смене файла или дорожки, повторной подготовке и нормальном закрытии приложения.

## Исправление рассинхронизации с VAD

В whisper.cpp 1.9.2 временные метки сегментов JSON относятся к исходной дорожке, а необработанные метки токенов в полном JSON могут оставаться во временной шкале, где VAD вырезал тишину. Если использовать токены напрямую, субтитры всё сильнее спешат.

Local Subtitle Studio теперь обнаруживает это расхождение, считает границы сегмента основной временной шкалой и переносит положение слов внутрь исходного сегмента. На проверенном фрагменте Brooklyn Nine-Nine первая реплика находится около 2,35 секунды; со стандартным упреждением SRT начинается около 2,30 секунды, а не с 0,00. Старый SRT нужно создать заново. Дополнительный предел в семь секунд не позволяет даже ошибочно длинной границе Whisper держать короткую реплику на экране десятки секунд; предел можно изменить в расширенных настройках.

Для полнометражного материала временный WAV дополнительно делится на перекрывающиеся восьмиминутные окна. Каждое окно запускается с чистым текстовым контекстом, поэтому одна ошибочная фраза не должна тянуться до конца фильма. Перекрытие при сборке принадлежит только одному окну и не создаёт дублей. Подозрительный фрагмент автоматически повторяется с отключённым переносом контекста; если и повторная попытка зациклилась, повреждённый SRT не сохраняется, а программа показывает время проблемы.

## Ошибки распознавания

Автоматически и безопасно исправляются только механические проблемы: пробелы, переносы, близко расположенные полные дубликаты и ограниченный набор однозначных русских слов с `ё`. Неоднозначные варианты вроде «все/всё» не угадываются. Программа помечает реплики с низкой уверенностью Whisper и другие проблемы читаемости; кнопка проверки открывает только эти места в небольшом редакторе.

Смысловое исправление имён, терминов и «кривых» фраз требует контекста и отдельной языковой модели. Планируется необязательный локальный этап на `llama.cpp`: он будет получать соседние реплики, уверенность Whisper и пользовательский словарь, возвращать структурированные предложения и не менять временные метки. Исходный и исправленный текст должны показываться рядом, а спорные изменения — подтверждаться пользователем. Подробная схема и ограничения описаны в [ADR 0007](docs/architecture/0007-contextual-subtitle-correction.md).

## Несколько языков и MVO

Эти режимы спроектированы, но пока не выдаются за готовую функцию:

- Если на русской дорожке встречается французская речь, запуск Whisper с принудительным `ru` может превратить её в похожие по звучанию русские слова. Нужны определение языка по речевым фрагментам и повторное распознавание на найденном языке.
- Планируются два результата: вариант **по авторскому замыслу**, где непонятная исходной аудитории иностранная речь не переводится, и вариант **весь диалог**, где иностранная реплика переводится. Безопасная базовая пометка — `[французская речь]`; курсив будет отдельной настройкой оформления.
- Встроенный режим перевода whisper.cpp переводит только на английский. Для французского → русского нужна отдельная локальная модель перевода или явно включённый облачный сервис.
- Для MVO в интерфейсе появился экспериментальный флажок смешанной озвучки. Он требует вручную выбрать язык перевода, чтобы английское вступление не переключило весь файл на неверный язык, и помечает результат для проверки. Это пока не отделяет тихий оригинал от голосов перевода: оба сигнала уже смешаны в одних отсчётах аудио. Надёжное извлечение обеих речей потребует проверенной модели разделения источников и обязательного отображения неопределённости.

Подробное решение и критерии готовности описаны в [ADR 0005](docs/architecture/0005-multilingual-dialogue-and-voice-over.md).

## Запуск из IntelliJ IDEA или терминала

Нужен JDK 17 или новее для запуска Gradle. Проект использует JDK 21 и при необходимости умеет получить toolchain автоматически.

В терминале:

```powershell
.\gradlew.bat run
```

В IntelliJ IDEA откройте окно Gradle и запустите `Tasks → application → run`. Spring Boot здесь намеренно нет: это обычное JavaFX-приложение.

Создать автономную папку приложения:

```powershell
.\gradlew.bat packageAppImage
```

Создать portable‑ZIP:

```powershell
.\gradlew.bat packagePortableZip
```

## Тесты

Модульные тесты:

```powershell
.\gradlew.bat test
```

Интеграционные проверки с FFmpeg/FFprobe:

```powershell
.\gradlew.bat integrationTest
```
