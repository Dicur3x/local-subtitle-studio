# Local Subtitle Studio

[English version](README.md)

> **Разработка остановлена.** Local Subtitle Studio остаётся доступным как исследовательский прототип под лицензией MIT, но больше не развивается и не рекомендуется как рабочая программа для создания субтитров. Новых выпусков, обновлений зависимостей и пользовательской поддержки не планируется.

Local Subtitle Studio — экспериментальное настольное приложение для Windows, создающее SRT локально, без загрузки исходного видео в интернет. Публичная [Alpha 2](https://github.com/Dicur3x/local-subtitle-studio/releases/tag/v0.1.0-alpha.2) демонстрирует рабочую обработку одного файла, но это незавершённая программа: в тексте и таймкодах возможны ошибки.

## Почему разработка остановлена

Проект начинался как попытка сделать локальное создание субтитров понятным обычному пользователю. Позднее сравнение показало, что зрелые open-source программы уже значительно лучше закрывают почти весь задуманный сценарий:

- [Subtitle Edit](https://github.com/SubtitleEdit/subtitleedit) объединяет полноценный редактор субтитров, форму звуковой волны и синхронизацию, распознавание через разные движки (включая whisper.cpp и Faster-Whisper-XXL), локальный и сетевой перевод, пакетную обработку и средства проверки.
- [Buzz](https://github.com/chidiwilliams/buzz) предлагает более простой кроссплатформенный интерфейс для локального распознавания и перевода с несколькими движками.
- [Faster-Whisper-XXL](https://github.com/Purfview/whisper-standalone-win) — функциональный Windows-движок и консольная программа для распознавания. Его также можно использовать внутри Subtitle Edit.

Продолжение Local Subtitle Studio как ещё одной универсальной программы означало бы в основном повторение этих проектов с менее зрелым редактором, меньшим выбором движков, слабее проработанным переводом и ускорением на видеокарте. Поэтому честнее остановиться, чем предлагать пользователям и участникам вкладываться в дублирующую альфа-версию.

Для реальной работы с субтитрами в первую очередь стоит попробовать **Subtitle Edit**. Если его интерфейс покажется перегруженным — **Buzz**. Для видеокарты AMD разумно начать с whisper.cpp и Vulkan; ускорение Faster-Whisper в основном рассчитано на NVIDIA CUDA.

## Что реализовано в прототипе

В Alpha 2 есть:

- локальная проверка видео и аудиодорожек через FFprobe;
- управляемая установка FFmpeg, whisper.cpp, моделей Whisper и Silero VAD;
- выбор аудиодорожки и языка речи;
- распознавание перекрывающимися восьмиминутными окнами с чистым контекстом Whisper;
- восстановление после отмены, закрытия или сбоя с повторным использованием подготовленного аудио и завершённых окон;
- защита от длинных повторяющихся и зацикленных галлюцинаций распознавания;
- таймкоды с учётом границ речи, перенос текста и проверка SRT на читаемость;
- небольшой редактор для отмеченных проблемных реплик;
- сохранение UTF-8 SRT без перезаписи существующего файла: рядом с видео, в папке `Subs` или в выбранной папке;
- русский и английский интерфейсы;
- автономная portable-сборка для Windows.

Самая необычная часть прототипа — восстановление по контрольным точкам. Её можно использовать как основу или пример при доработке зрелого проекта. Технические решения сохранены в [`docs/architecture`](docs/architecture), а исторический объём планов — в [`ROADMAP.md`](ROADMAP.md).

Незавершённая реализация перевода в отдельной ветке не входит в Alpha 2 и не будет выпускаться как поддерживаемая Alpha 3.

## Как запустить последнюю альфа-версию

Последняя публичная сборка — [v0.1.0-alpha.2](https://github.com/Dicur3x/local-subtitle-studio/releases/tag/v0.1.0-alpha.2):

1. Скачайте и распакуйте portable-ZIP для Windows.
2. Запустите `Local Subtitle Studio.exe`.
3. Откройте **Компоненты** и установите необходимые программы и модель распознавания.
4. Выберите видео, аудиодорожку и язык речи, затем нажмите **Создать SRT**.

Java устанавливать не нужно: её среда уже включена в сборку. В portable-режиме настройки, загруженные компоненты, модели и данные восстановления хранятся в папке `data` рядом с программой. Медиафайлы остаются на компьютере пользователя.

Сборка сохранена только для ознакомления. Со временем ссылки загрузки, контрольные суммы и версии сторонних компонентов могут устареть; исправлений не будет. Любые созданные субтитры необходимо проверять вручную.

## Запуск из исходного кода

Это JavaFX-приложение на Gradle и JDK 21, а не Spring Boot.

```powershell
.\gradlew.bat run
```

Запуск модульных тестов:

```powershell
.\gradlew.bat test
```

Создание автономной папки приложения и portable-ZIP:

```powershell
.\gradlew.bat packageAppImage
.\gradlew.bat packagePortableZip
```

Код остаётся доступным для изучения и повторного использования, но при создании issues и pull request не следует ожидать ответа или нового выпуска.
